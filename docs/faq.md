## AI Usage Guidelines (How to Build with Coding Agents)

Using AI coding assistants (Codex, Claude, ChatGPT, Cursor, Gemini, Copilot, etc.) is fully permitted and encouraged.

### 🟢 Recommended AI Uses:

- Scaffolding components, schemas, and state handlers rapidly.
- Generating rigorous JSON input schemas for `document.modelContext.registerTool`.
- Drafting and refining README documentation, tool descriptions, and architecture diagrams.
- Writing unit tests and edge-case validation handlers for tool execution.

### 🔺 Things to Avoid:

- Over-promising in descriptions with buzzwords rather than describing actual working code.
- Generating unverified boilerplate that fails silently during tool execution.
- Vague or generic project naming.
