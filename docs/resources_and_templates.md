# Developer Resources, SDKs & Starter Templates

---

## Core Specifications & Documentation
- [**WebMCP W3C Community / GitHub Repo**](https://github.com/webmachinelearning/webmcp): Specification text, architecture explainers, and open discussion.
- [**Google Chrome WebMCP Docs**](https://developer.chrome.com/docs/ai/webmcp): Official Google developer guides for browser-level tool registration.
- [**WebMCP Origin Trial Guide**](https://developer.chrome.com/blog/ai-webmcp-origin-trial): Details on browser flags and rollout.
- [**WebMCP Security & Prompt-Injection Guide**](https://developer.chrome.com/docs/ai/webmcp/secure-tools): Securing client-side exposed tools against malicious inputs.
- [**OpenAI WebMCP Guide**](http://learn.chatgpt.com/docs/webmcp): Official OpenAI guidance on agent tool calling in the browser.
- [**OpenAI Showcase**](https://developers.openai.com/showcase?view=webmcp-apps): Live examples of agent-native web applications.

---

## Framework Integrations & Helper Packages
- [**use-webmcp-tool (npm)**](https://www.npmjs.com/package/use-webmcp-tool): React hook for registering and managing WebMCP tools within component lifecycles.
- [**Angular WebMCP Guide**](https://angular.dev/ai/webmcp): Native Angular bindings and documentation.
- [**Chrome DevTools WebMCP Inspector**](https://developer.chrome.com/docs/devtools/application/webmcp): How to inspect and debug tools in DevTools.
- [**WebMCP Tool Evals**](https://developer.chrome.com/docs/ai/webmcp/evals): Tool accuracy and execution evaluation framework.
